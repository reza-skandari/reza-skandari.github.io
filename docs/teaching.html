Approach

Students code in the browser with GitHub Codespaces, so nothing needs installing, and use GitHub workflows to practise the version-controlled collaboration used in industry. In-class exercises, quizzes and automated formative feedback show students straight away how they are progressing.

I teach students to treat generative AI as a collaborator to be questioned rather than an oracle: they use it for coding, data analysis and writing, but verify its output, keep their work reproducible and consider its ethical use.
